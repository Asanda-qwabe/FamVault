# FamVault
FamVault is a family financial management platform that allows households to manage shared budgets, set spending limits for members across different banks, and maintain a secure emergency wallet for unexpected situations.

The system allows a family group administrator (usually a parent or guardian) to create a shared financial group where members can have controlled spending limits while still using their own bank accounts. Each member can belong to different banks, but the platform provides a unified dashboard to monitor spending, limits, and financial activity.

FamVault also introduces an Emergency Mode Wallet, a small reserved fund that can be accessed during urgent situations such as losing a phone, wallet, or bank card.

The goal of FamVault is to simplify family budgeting, financial transparency, and emergency access to funds.
